# loomlog v0.3 — 振り返り(reflection)＋クエリ設計

> 2026-06-09 確定。Codex価値レビュー＋本人の方針(学術メソッドに基づく振り返り型)を反映。
> 目的: 「毎日何したか忘れる」を機械で想起できるようにし、その事実の上に
> **学術的に裏付けられた振り返りの型**を載せる。capture は従来どおり0トークン/no-API-key。

## 役割分担(loomlogの思想に忠実)

```
loomlog が「事実(What)」を機械で用意(0token)
   → 学術フレームが「型」を与える
   → ホストモデルが内省(So What / Now What)を対話で進行
   → 結果を vault に保存し返す(Reflections/ ノート, captureに上書きされない)
```

## 1. クエリ面 `loomlog <prompt>`(機械ルーティング・0token・素のターミナル可)

既知サブコマンド(capture/scan/init/report/reflect/reflect-save)以外の第1引数は**クエリ**として解釈:

| 入力 | 意味 |
|---|---|
| `loomlog 2026-06-08` | 特定の日 |
| `loomlog today` / `yesterday` | 当日 / 前日 |
| `loomlog week` (`7d`) / `month` (`30d`) | 直近7日 / 30日 |
| `loomlog <project>` | そのプロジェクト履歴(既定: 直近90日, `--since`で上書き) |
| `loomlog patterns` (`stats`) | どういう作業が多いか(コマンド種別/プロジェクト時間配分/エージェント配分/多忙日/詰まり総数/成果commit数) |

- 既定は人間可読、`--json` でホストモデル用。
- 真の自然言語(「先週AWSで詰まったやつ」)は `/loomlog` スラッシュコマンドでホストモデルがNL→クエリ変換。

## 2. キャプチャの種(0token・今捨てている情報の回収)

- **`commits: string[]`**(本リリースの目玉): shell/Bash コマンドから git commit メッセージ(subject)を抽出。
  `-m "..."` / `-m $'...'` / heredoc `$(cat <<'EOF' ... EOF)` 対応。redact+cap。
  → 「何を成し遂げたか」の一次記録。WSNの"What"・KPTの"Keep"を実体化。
- `schemaVersion`(将来の移行用, 各レコードに付与)。
- (v0.4送り) error fingerprint / marker / promptTurns / drift — 設計だけ残す。

## 3. 振り返りの型(4メソッド × loomlogデータ)

`loomlog reflect --template <t> [scope] --json` が **事実(What)JSON + 型の段階定義** を出力。
ホストモデルがそれを使って対話的に内省を進行 → `loomlog reflect-save` で保存。

- **wsn**(既定・日次 / Borton→Driscoll): What(loomlog記入: 意図/変更/作業種別/詰まり/成果commit) → So What(1–2問) → Now What(1問)
- **gibbs**(週次/月次): 記述/感情/評価/分析/結論/行動計画(6段)
- **aar**(詰まり期間 / 米軍4問): 期待(宣言intent) → 実際 → 差分の原因 → 学び
- **kpt** / **ywt**(軽量・日次別選択): Keep/Problem/Try, やった/わかった/つぎ

既定マッピング: 日次=wsn, 週次=gibbs, `--template` で任意切替。

## 4. 保存し返す(vault)

- 振り返りは **`Reflections/<date>.md`**(週次は `Reflections/<date>-weekly.md`)に保存。
  capture は Reflections/ を触らないので**上書きされない**。
- 各ノートは対象 Daily/Project へ `[[wikilink]]` で逆リンク → グラフに出る(色: 紫)。
- `loomlog reflect-save --date <d> --template <t> [--weekly]` が stdin の markdown を
  該当ノートに追記(atomic)。スラッシュコマンドが内省完了後に呼ぶ。

## 5. スラッシュコマンド(対話式・save-back)

- Claude plugin: `/loomlog:reflect`(WSN日次, 対話, 保存) / `/loomlog:weekly`(Gibbs週次, 保存)。既存 `/loomlog:report` は残す。
- Codex / Gemini: reflect プロンプトを1本追加(WSN)。

## スコープ外(v0.4)
error fingerprint で**再発する詰まり**, marker/promptTurns で**関心ドリフト・学びの結晶化**,
agent fit profile, MCP 自由問い合わせ。今回は土台(commits/クエリ/型)を固める。
